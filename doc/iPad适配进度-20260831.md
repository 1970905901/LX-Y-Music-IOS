## 目标

一个 universal 包（同一 IPA）同时运行在 iPhone 与 iPad：

- iPhone：仅竖屏（系统锁）。
- iPad：竖屏 + 横屏。
- 无手动「横屏锁定」开关，方向完全由系统级配置裁决。

## 已完成 ✅

### 1. 原生工程（一个包）
- `TARGETED_DEVICE_FAMILY = "1,2"`（iPhone + iPad）。
- Info.plist：`UIDeviceFamily = [1, 2]`；`UISupportedInterfaceOrientations`（iPhone）仅 Portrait，
  `~ipad` 为 Portrait + Landscape 左右。

### 2. 横屏基础设施
- `useHorizontalMode`：按窗口宽高比 >1.2 判定横屏。
- `landscapeLayout.ts`：按长边分档响应式布局。
- `LandscapeCentered` / `LandscapeDetailLayout`：限宽居中 / 横屏分栏组件。
- `pixelRatio` 上限 1.2：避免平板 pixelRatio(=2) 把尺寸算大约 1.55 倍。
- `PageContent`：竖屏宽度 ≥700pt 时内容限宽居中、背景全屏。

### 3. 页面横屏适配（列表响应式列数已全覆盖）
所有歌曲列表统一走 `OnlineList`，其内部 `getRowInfo(rowType)` + `useHorizontalMode`
动态计算 `numColumns`，变更时用 `key` 强制重挂载 FlatList。

- 详情页：Home/PlayDetail 横屏整树切换；AlbumDetail/ArtistDetail/SonglistDetail
  用 `LandscapeDetailLayout` 分栏（左栏 340/420 + footer PlayerBar）。
- 评论页：横屏「热门/最新」并排分栏（竖屏保持 PagerView）。
- 下载管理 / 相似歌曲 / QQ 歌单 / 酷狗歌单 / WebDAV / 本地下载 / 每日推荐 /
  订阅专辑 / 关注歌手 / 我的列表 / 搜索 / 播放历史：横屏双列或网格自适应。
- 排行榜 / 设置 / 歌单列表 / 我的列表：专用横屏或 master-detail 分栏。

### 4. 浮层 / 转场 / 细节打磨
- `shadow.ts` 统一跨平台阴影，iOS 补齐投影，移除 Android elevation。
- pop 转场返回宽度动态读取；菜单/下拉面板窗口变化自动关闭。
- 对话框 / 文件选择器 / 加入歌单弹窗在横屏限宽 760pt。
- 多任务退出（UIRequiresFullScreen 方案 A）、列表响应式、键盘规避、元数据能力门控。
- 控制中心封面、动态背景、进度条拖动、列表滚到底等 iOS 修复。
